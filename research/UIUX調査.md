# 資格アプリ UI/UX 調査

App Store（日本）から資格・学習アプリを横断収集し、機能とUIのパターンを整理したものです。

```
research/apps.csv     収集した全4,554アプリ（機能タグ18項目つき）
research/sheet-1..3.jpg  上位30アプリのスクリーンショット一覧
```

## 収集したもの

| 区分 | 件数 |
|---|---|
| 収集アプリ総数 | **4,554** |
| うち学習・資格系 | 3,961 |
| うち評価50件以上（実際に使われている） | 782 |
| スクリーンショットを取得したアプリ | 30（88枚） |

70種類の検索語（資格名・試験名・学習手法）で iTunes Search API を横断し、
重複を除いたものです。平均評価4.39、有料アプリは9%。

## 頂いた参考2本の分解

### テス友（JSTQB／ソフトウェアテスト技術者試験）

**ホーム** — 上から順に

1. マスコット（ドクターQ）の吹き出しで次の一手を提案（「間違えた問題を優先」を整理して弱点を克服しよう）
2. **レーダーチャート**（1章〜6章の到達度を6角形で）
3. 出題条件を**ホームで直接指定**する3つのドロップダウン … 問題数(40問)／出題傾向(特定の章を優先)／章数(6章)
4. **単一の大きなCTA「出題」**（オレンジ／鉛筆アイコン）
5. 参照系の3ボタン … シラバス／用語集／履歴

**問題画面**

- ヘッダーに「40問中1問目」
- **問題／解説のタブ切替**、右上に**解答時間 00:01:53**
- 解説側に「正解」バッジ（緑）と自分の解答「D」
- 下部に**問題ナビのチップ**（問1〜問5、現在をハイライト）＋「次の問題へ」の全幅ボタン

### 英語学習アプリ

1. **要復習21件**を円形カウンタで提示 → その真下に**単一CTA「スタート」**（オレンジ）
2. **連続学習日数** … 火〜今日の曜日チェック（青丸✓）、「42日 現在の記録」「42日 自己ベスト」を炎アイコンで挟む
3. **週間カレンダー** … 週ごとの学習量を棒グラフ、目標時間1hの点線
4. キツネのマスコット

**2本に共通する型**：ホームは「今やる1つ」に集約し、大きな単色CTAを1つだけ置く。
その上に「なぜ今それをやるのか」の根拠（要復習件数・到達度チャート）を示す。
継続は日数と自己ベストで見せる。

## 上位100アプリは「機能が多いから」勝っているわけではない

評価数の多い上位100本と、それ以外682本で機能の出現率を比べました。

| 要素 | 上位100 | その他 | 差 |
|---|---|---|---|
| ランキング | 11% | 6% | +5pt |
| 通知・リマインド | 12% | 8% | +4pt |
| 用語集 | 14% | 11% | +3pt |
| 解答時間の計測 | 12% | 10% | +2pt |
| 苦手の自動抽出 | 31% | 40% | **−9pt** |
| 習熟度の可視化 | 16% | 24% | **−8pt** |
| 出題条件の選択 | 10% | 18% | **−8pt** |
| 復習・間隔反復 | 36% | 42% | −6pt |

差はどれも小さく、しかも**上位のほうが機能訴求は少ない**項目が並びます。
機能の数では差がついていない、というのがこの調査でいちばん明確に出た結論です。
スクリーンショットを見ると、上位が押しているのは**収録問題数・解説の質・画面の完成度**でした。

## スクリーンショットから読み取れた実UIのパターン

- **章・分野別の進捗リスト**が過去問アプリの主要ナビゲーション。
  1行1章で右端に「0/122」「0/365」の分数を置く形（行政書士2026、数学検定トレーニング）。
  到達度を面で見せるより、次に開く場所が決まりやすい。
- **解説画面の色分け**。重要語を赤字、条文引用を枠囲み、間違いやすい箇所に赤丸（行政書士2026）。
- **マークシート型の解答UI**。1(1)〜1(5) の行に①〜④の丸を並べ、解答時間と残り時間を併記。
- **模試の入口を2段階に分ける**。「簡易レベル診断 5分」と「本番想定模試 20分〜」（SPI対策）。
- ストア用スクショはほぼ全社が**上部に大きな日本語コピーの帯＋端末モックアップ**という同一構図。

## 当アプリとの差分

| | 当アプリ | 参考2本・上位アプリ |
|---|---|---|
| ホームのCTA | 演習5枚が等価に並ぶ | **単一の大きなCTA**＋その根拠を上に |
| 出題条件 | 別画面で設定 | **ホームで直接**（問題数・範囲・傾向） |
| 到達度 | 20回×5列のマトリクス | レーダーチャート／**分野別の分数リスト** |
| 継続 | 連続日数の数字のみ | **曜日チェック＋自己ベスト＋週間棒グラフ** |
| 解答時間 | なし | 1問ごとに計測・表示 |
| 問題ナビ | 模試のみ | 演習でもチップ表示 |
| 解説 | **なし** | 35%が搭載、上位ほど質を訴求 |
| キャラクター | なし | 6%（ただし参考2本は両方あり） |

すでに持っているもの（段位・実績・到達度・目標・付箋・模試）は、
出現率で見れば上位3〜17%の機能で、揃っているほうです。
足りないのは**ホームの導線設計**と**継続の見せ方**、そして**解説**でした。

## 打ち手の案

すぐ効きそうな順です。

1. **ホームを単一CTAに再編** — 「要復習◯問」を大きく出し、その下に「今日の◯問をはじめる」を1つ。
   他のモードは下に小さく畳む。（参考2本に共通する最重要の型）
2. **出題条件をホームに載せる** — 問題数・範囲・傾向をドロップダウンでホームに。テス友の型。
3. **継続の見せ方を強化** — 曜日チェック行、自己ベスト、週間の学習量バー。
4. **分野別の進捗リスト** — 「法令 0/551」形式の行を追加。マトリクスと併存させる。
5. **解答時間の計測** — 1問ごと・模試全体。
6. **解説** — 現状の最大の差分。条文を典拠に一から書き起こす必要があり工数は大きいので、
   まずは正答肢の根拠条文へのリンクだけ、といった段階的な着手が現実的。
