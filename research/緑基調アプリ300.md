# 緑を基調にした学習アプリ 300本

`research/apps.csv` に集めた4,554本について、**App Store の実際のスクリーンショットを1枚ずつ取得して
画素単位で色を測り**、緑が基調のものを抜き出した記録です。アイコンの印象ではなく画面そのものを見ています。

| 出力 | 中身 |
|---|---|
| `green-apps.csv` | 緑基調アプリ300本（評価数順・実測した緑の色つき） |
| `green-screens.jpg` | 上位12本の実画面 |
| `green-leaders.jpg` | 同ジャンルの首位グループ（独学TODAY系）の画面10枚 |
| `green-icons.jpg` | 300本のアイコン一覧 |
| `green-swatches.png` | 300本から実測した緑300色を色相順に並べた色見本 |

## 測り方

1. 4,554本の App Store 商品ページを取得（3,620本でスクショURLを確認）
2. 各アプリの1枚目のスクショを460px幅で取得。**縦横比1.4以上のものだけ**を採用し、
   正方形のアイコンや横長の宣伝画像を除外
3. 画素をHSVに直し、彩度0.22未満・明度0.14未満（白・黒・灰）を除く
4. 残った有彩色のうち最頻の色相帯を「その画面の基調色」とする
5. 緑（色相75〜165°）が最頻かつ有彩色の45%以上を占めるものを「緑基調」と判定
6. 緑と判定した画素のRGB中央値を、そのアプリの緑として記録

判定できたのは3,620本。緑基調は**404本（11.2%）**、うち評価数上位300本をCSVにしています。

| 基調色 | 本数 | 割合 |
|---|---:|---:|
| 青 | 1,505 | 41.6% |
| 青緑 | 434 | 12.0% |
| ほぼ無彩色 | 409 | 11.3% |
| **緑** | **404** | **11.2%** |
| 橙 | 343 | 9.5% |
| 赤 | 310 | 8.6% |
| 紫 | 84 | 2.3% |
| 桃 | 67 | 1.9% |
| 黄 | 64 | 1.8% |

学習アプリ全体では青が圧倒的です。ところが**絞り込むほど緑が上がってきます。**

| 母集団 | 緑 | 青 | 備考 |
|---|---:|---:|---|
| 全3,620本 | 11.2% | 41.6% | 青が4割 |
| 資格・検定・試験 1,706本 | 11.4%（2位） | 45.5% | まだ青 |
| 「過去問」を名乗る 304本 | **16.1%（2位）** | 33.9% | 青が減り緑が増える |
| うちレビュー300件以上 29本 | **34.5%（1位）** | 6.9% | **青がほぼ消える** |

過去問アプリの上位グループでは緑と青緑が7割を占め、青は2本しかありません。

## 同ジャンルの首位グループ

`green-leaders.jpg` は「独学TODAY」（Trips LLC）系の5アプリ。宅建・ITパスポート・行政書士・公務員・基本情報を
同じ設計で横展開していて、**どれも深緑**です。

| アプリ | 評価 | 評価数 | 実測した緑 |
|---|---:|---:|---|
| 宅建 過去問 2026 | 4.76 | 41,205 | `#01843A` |
| ITパスポート 全問解説 | 4.72 | 23,012 | `#279F00` |
| 行政書士 過去問 2026 | 4.73 | 5,993 | `#03843A` |
| 基本情報技術者試験 全問解説 | 4.71 | 2,631 | `#279F00` |
| 公務員試験 全問解説 | 4.75 | 1,414 | `#01602F` |

画面の作りは5本とも共通で、本アプリの現状と構造がほぼ同じです。

- 深緑のヘッダーバー、白抜き文字
- 「問題」「設問」の緑ベタ塗りラベルチップ
- 白地の本文、末尾に灰色の「出典：令和◯年度試験 問◯」
- **選択肢は橙のベタ塗りボタンを画面下に横並び**（ア／イ／ウ／エ）
- 分野別一問一答は**`0/122` のカウンタ付き高密度リスト**、行頭に小さな緑アイコン

## 300本の緑はどんな緑か

色相の中央値140°、彩度0.63、明度0.63。`green-swatches.png` が実測300色です。

| 系統 | 本数 |
|---|---:|
| 青緑寄りの緑（エメラルド） | 91 |
| 中間の緑 | 88 |
| 深緑 | 62 |
| 明るい緑 | 30 |
| 黄緑（ライム） | 29 |

**明るいライムは少数派**で、評価数上位の資格アプリはほぼ深緑〜中間の緑に寄っています。
ライムが効いているのは小学生向け（ひとコマ漢字 `#94E03E`）や英語（Duolingo `#79C902`）など、
年齢層が低いか娯楽寄りのものです。

## 緑と何を組んでいるか

| 相方の色 | 本数 |
|---|---:|
| **なし（緑＋白・灰だけ）** | **141** |
| 青 | 46 |
| 橙 | 43 |
| 赤 | 24 |
| 青緑 | 22 |
| 黄 | 21 |

**300本中141本＝47%が、緑1色と無彩色だけで組んでいます。**2色目を足す場合は橙か赤（＝暖色）が多く、
青を足しているものは青がイラストや図版由来のことが多いです。

## 本アプリへの含意

いまの配色は紺を主色にしていますが、上の数字はそれと逆を示しています。

- 全体では青が最多だが、**過去問という絞り込みでは緑が首位**。青は上位から消える
- 同ジャンルの最上位5本（評価4.7前後）が全部深緑で、しかも**本アプリと同じ画面構造**
- 緑にする場合は、明るい緑ではなく **`#016A33`〜`#03843A` あたりの深緑**が実勢
- 相方は不要（47%が緑＋無彩色）か、足すなら橙・赤

現行の4色（紺・朱・緑・紫）の役割はそのままに、**主色の紺を深緑に、いまの緑（正解）を別の緑に振り直す**か、
あるいは紺を残したまま**ヘッダーだけ深緑**にする、のどちらかで実勢に寄せられます。

## 再現

```bash
cd scratchpad/ux
python3 art.py        # 4,554本のアイコンURLを Lookup API で取得
python3 geticons.py   # アイコンを128pxで取得
python3 allpages.py   # 商品ページを取得
python3 fixurl2.py    # 縦横比1.4以上＝スクショ、としてURLを抽出
python3 dlall.py      # スクショを460px幅で取得
python3 scan.py       # 画素から基調色を判定
```
