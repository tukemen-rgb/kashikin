# 復元した5年分（令和元年〜令和5年）

最初にアップロードされた5ファイルを、検証済みデータから作り直したものです。

| ファイル | 回 | 元ファイルにあった問題 |
|---|---|---|
| `令和元年_2019_第14回.docx` | 第14回 | 問5⇔問6、問7⇔問8 が入れ替わっていた |
| `令和2年_2020_第15回.docx` | 第15回 | **正解番号が50問中23問で公式正答と食い違い** |
| `令和3年_2021_第16回.docx` | 第16回 | 問題文・正解は一致（解説のみ別論点） |
| `令和4年_2022_第17回.docx` | 第17回 | **中身が令和3年（第16回）の問題50問だった** |
| `令和5年_2023_第18回.docx` | 第18回 | 問題文・正解は一致（解説のみ別論点） |

いずれも解説は全50問が設問とは別の論点を説明していました。詳細は `検証結果.md`。

## 中身

各ファイルは2部構成です。

1. **問題** — 分野の見出し、【問題 N】、設問、記述ａ〜ｄ、選択肢①〜④、注記、図表
2. **正解と着眼点** — 正解、分野・テーマ（47分類）、条文名、狙われている点

### 解説を載せていない理由

アップロードされた5ファイルの解説を全250問について照合したところ、
設問とは別の論点を説明しているものがほとんどでした。
**誤った解説は学習の妨げになる**ため、推測で書き直すことはしていません。

代わりに、原文から機械的に取れるものだけを付けています。

- **出題テーマ** — 47分類。条文と語の2系統で判定
- **条文名** — 出題者自身が本文で括弧書きしているものだけ（推測なし）
- **狙われている点** — 選択肢どうしの対立から検出した引っかけの型12種と、その着眼点

## 検証

生成した5ファイルを開き直し、**1,735項目**（250問の設問・記述・選択肢・注記と、250問の正解）を
`data/questions.json` と突き合わせて **不一致0件**を確認しています。

```bash
python3 tools/restore/make_docx.mjs   # 生成
python3 tools/restore/verify.py       # 検証
```

原文の出典は日本貸金業協会が公開している試験問題PDF・正答PDFです。
