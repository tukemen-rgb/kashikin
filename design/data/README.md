# デザイン用の見本データ

画面設計に使うための、問題と解答の見本です。**全1000問は要りません。**
必要なのは「レイアウトが壊れる条件を網羅した見本」なので、24問を意図的に選んであります。

| ファイル | 用途 |
|---|---|
| `sample-questions.json` | コードから読む場合。全フィールドと集計メタつき |
| `sample-questions.xlsx` | Claude Design に直接アップロードする場合（4シート） |

全1000問が要るときは `data/questions.json`（プログラム用）と
`data/questions.csv`（表計算用・BOM付きUTF-8）にあります。

## 守ること

**設問・記述ａ〜ｄ・選択肢・注記は公式PDFの原文そのままです。**
表示上の改行・字下げ・濃度・下線を加えるのは自由ですが、
**文字を足す・削る・置き換えることはできません。**
アプリ側では、描画されたテキストが原文と一字一句一致することを
全1000問について毎ビルド検証しています（現在 不一致0件）。

## なぜこの24問なのか

| 選んだ理由 | 該当 |
|---|---|
| 設問がいちばん長い（956字・9文に割れる） | K01-04 |
| 設問がいちばん短い（53字） | K01-36 |
| 選択肢がいちばん長い（499字） | K03-47 |
| 記述ａ〜ｄがいちばん長い（357字） | K06-01 |
| 図表問題（表を構造化して保持） | K15-48・K19-48 |
| 出題形式3種 × 否定形あり／なし | 6問 |
| 4分野の代表 | 4問 |
| 注記つき（注の定義文が本文と別に付く） | K18-25 |
| 引っかけの型が3つ以上 | K04-18 |
| 引っかけなし・条文名あり | K01-18 |
| 頻出度がいちばん高い | K02-06 |
| 第20回（令和7年度）から | 4問 |

各行の `sampleFor` 列にこの理由が入っています。
**いちばん長い設問（K01-04）で崩れないかを最初に確認してください。**

## フィールド

| 名前 | 中身 |
|---|---|
| `id` `label` `era` `num` | K01-04 ／ 第1回 ／ 平成21年度 ／ 4 |
| `section` | 法令・貸付実務・資金需要者保護・財務会計 |
| `theme` | 47テーマのどれか |
| `format` | `single` 単純択一／`combo` 組合せ／`count` 個数 |
| `negative` | 「適切でないもの」を選ぶ問題かどうか |
| `stem` | 設問（原文） |
| `statements` | 記述ａ〜ｄ（原文）。`combo` と `count` にだけ入る |
| `options` | 選択肢①〜④（原文） |
| `note` | 注記（原文）。100問に付く |
| `table` | 図表問題2問だけ、構造化した表 |
| `answer` | 正答（1〜4） |
| `articles` | 条文名。出題者が本文で括弧書きしているものだけ |
| `traps` | 引っかけの型のID。詳細は `meta.引っかけの型` |
| `topicRank` | 頻出度 |
| `len` | 設問・記述・選択肢の字数（レイアウト検討用） |

## 配色

深緑 `#0F7A3C`＝操作　／　朱 `#C6402A`＝先へ進む・誤り　／
紺 `#134E8C`＝できた　／　紫 `#6A4A9C`＝あとで見直す。

コンポーネントは `design/` に12枚のカードとして置いてあります（`design/index.html` で一覧）。

## 再生成

```bash
python3 tools/design/06_sample_data.py   # JSON
python3 tools/design/07_sample_xlsx.py   # XLSX
```

XLSX に数式は入れていません。この環境で LibreOffice が起動せず数式を検算できないため、
集計は生成時に確定値として書き込んでいます。見本を差し替えるときは再生成してください。
