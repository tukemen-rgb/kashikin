# 貸金業務取扱主任者 過去問1000＋学習アプリ

第1回（平成21年度）〜第20回（令和7年度）の**全1000問**を、日本貸金業協会が公開している
公式PDFから機械的に取り込み、複数の方法で裏付けを取ったデータセットと、それを使う学習アプリです。

```
data/questions.json   全1000問（アプリ・プログラム用）
data/questions.csv    同上（表計算用・BOM付きUTF-8）
data/themes.json/.csv 47テーマの一覧（出題数・代表条文つき）
app/index.html        学習アプリ（単一ファイル。ダブルクリックで開けます）
app/template.html     アプリの雛形（データ注入前）
design/               デザインシステム（Claude Design に push できる形）
design/data/          画面設計用の見本データ（見本24問・JSON と XLSX）
tools/                データ生成・検証スクリプト
research/             資格アプリ4,554本のUI/UX調査
research/緑基調アプリ300.md  スクショの画素から基調色を測った色調査
検証結果.md            アップロードされた7ファイルの検証結果
```

## データが正しいことの裏付け

### 1. 正答 1000件 — 公式正答PDFと一致

第1〜20回の正答PDFから抽出した数字をそのまま採用。1000/1000。

### 2. 本文 5053項目 — 別の抽出エンジンで100%一致

同じ公式PDFを **pypdfium2**（本番の抽出に使った pypdf とは別エンジン）で読み直し、
問題文・ａ〜ｄの記述・選択肢を突き合わせた結果、**5053/5053（100.00%）が一致**。
抽出プログラムの取りこぼしや混入がないことを確認しています。

### 3. 数字を含む本文 2196項目（第10〜20回）— 他社データと一致

過去問ドットコムの該当550ページを取得し、数字も含めて照合。**2193/2196（99.86%）が一致**。
残る3件を個別に確認したところ、2件は照合窓のずれ、1件は**他社側の誤記**でした
（令和2年度 問9 記述ｃ：公式は「残高の合計額は **0円**」＝数字のゼロ、他社は「**O円**」＝アルファベットのオー）。

### 4. 旧年度の数字 — ページ画像で確認

第1〜9回のPDFは数字が埋め込みフォントの字形として入っており、字形コードから数字への対応は
フォントごとに異なります（実測でオフセットが -4〜+11 とばらつく）。
本データは**字形コードではなく字形名**から復元しているためこの影響を受けませんが、
念のためページを画像に起こして目視確認しました。
例：第1回 問10 の「10万円／年4割（40％）／29.5％／150％」、第2回 問3 の「1人以上／2週間以内」
— いずれも本データと一致。

### 5. 参考：KakomonAI との照合は見送り

全20回を掲載している KakomonAI とも照合しましたが、選択肢3340件のうち**120件（3.6%）で本文が食い違い**、
個別に確認したところ**同サイト側の誤り**でした。
例：第2回 問3 ①を「2人以上」（公式は「**1人以上**」）、③を「1週間以内」（公式は「**2週間以内**」）。
本文が原文どおりでないため、照合の基準からは外しています。

### 抽出時に補正した点

- 埋め込みフォント由来の数字化け（`/c2691` → `1`）と全角数字の統一
- 版面の都合で割れた語（`第 1` ＋改行＋ `2条` → `第12条`）の結合
- 上付きの `(注)` と、末尾の注の定義文の切り分け
- 「…次のａ～」＋改行＋「ｄの記述のうち…」の折り返しを、記述ｄと誤認しないよう判別
- 引用文中の箇条書き `ａ．` を、解答対象の記述と区別
- 旧版面のノンブル（裸の数字）の除去
- 「ア 50万円 イ 100万円 ウ 40万円」のような対応表形式の選択肢は、区切りの空白を保持
- 図表2問（第15回 問48・第19回 問48）は段組みが崩れるため表を構造化

## アプリ

`app/index.html` を開くだけで動きます。サーバー不要・通信なし。学習記録はブラウザに保存されます。

### 長文を読みやすくする工夫（本文は一字も変えていません）

この試験は1問1000字近い設問があります。文字を足したり削ったりせずに、見せ方だけを整えています。

- **一文ずつ改行** — 括弧の外にある「。」で文を区切り、行を分けて字下げ
- **定義かっこを薄く** — 「（以下、本問において「本件基本契約」という。）」のような、
  読解に効かない定義部分の濃度を落として本筋を追いやすく（切替可）
- **設問の指示語を強調** — 「適切でないもの」「適切なものの個数」などにマーカー
- **ａ〜ｄを1枚ずつのカードに** — ○×を付けながら整理でき、○の数がその場で出ます
- **文字サイズ3段階** — 天板の「読みやすさ」で 小／中／大 と、定義かっこの濃さを切替

**画面に表示される文字列が原文と1文字も違わないことを、全1000問について自動で検証しています**
（問題文・記述・選択肢・注記のすべてで差異0件）。

### モード

ホームは「次にやる1つ」に集約しています。上に理由（復習の期日が来た問題数など）を出し、
その下に大きなボタンを1つだけ。出題条件（問題数・狙い・範囲）はそのすぐ下で指定できます。

- **範囲** — 全1000問／分野4つ／**テーマ47**／回20 から選択
- **出題の狙い** — おまかせ（弱点＋復習）／間違えた問題／未着手／頻出論点
- **模試** — 全20回それぞれ50問・2時間。**その回の公式合格基準点**で合否判定
- **復習** — 間違えた問題と付箋だけ
- **成績** — 分野別・回別の正答率、模試の記録

### 出題エンジンと分析（文章の自動生成はしていません）

公開ページから大規模言語モデルを呼ぶことはできませんし、仮にできても解説の自動生成はしません。
最初に検証した7ファイルで解説が壊れていた原因がまさにそれだからです。
代わりに、**原文からの抽出と解答履歴の統計**だけで成立する機能を載せています。

| 機能 | 中身 |
|---|---|
| 出題エンジン | 忘却曲線に沿った復習期日（SM-2風）＋分野別正答率による弱点重み付け |
| テーマ分類 | 47テーマ。条文と語の2系統で判定し、未分類は1問のみ |
| 条文名 | 本文の括弧書きから77条文の名前を抽出（第17条＝契約締結時の書面の交付 など） |
| 似ている問題 | 文字3-gramのTF-IDFコサイン類似度で各問に最大5問を事前計算 |
| 合格可能性 | 分野別正答率から本番構成27/15/5/3の得点分布を正規近似し合格確率を推定 |

### デザイン

`research/` に集めた実在の過去問アプリ（行政書士・社会福祉士・ケアマネ・SPI・数学検定・地理）
の画面を並べて突き合わせ、そこで共通していた作りに合わせています。

| 実機で共通していたこと | 本アプリでの反映 |
|---|---|
| ブランド色は1色。2色を対等に使わない | 主色は深緑1色。朱は「次へ」と強調だけの脇役 |
| ヘッダーは色ベタ塗り | 深緑のヘッダーバー＋朱の下罫 |
| 角丸はほぼ0。行は角のまま罫線で区切る | 角丸4px、一覧は1pxの罫線で区切るだけ |
| 影を落とさない | `box-shadow` は全廃。面は枠線のみ |
| グラデーションを使わない | XPバー等の階調を単色に |
| 一覧は詰めて多く見せる | 行の余白を詰め、テーマ47件を1画面に流し込む |
| 強調は赤い下線 | 「適切でないもの」等の着目語を朱の下線に（蛍光ペン風の塗りをやめた） |
| 「次へ」は朱色のボタン | 画面下に固定した朱の「次へ」 |

#### 色は4つだけ

橙・金・青緑がばらばらに増えていたので、**役割ごとに4色へ畳んで**います。
4分野の色分けもこの4色をそのまま使うので、覚える色が増えません。

| 色 | 意味 | 使う場所 |
|---|---|---|
| 深緑 `#0F7A3C` | 操作するもの | ヘッダー・ボタン・リンク／**法令** |
| 朱 `#C6402A` | 先へ進む／誤り | 「次へ」「学習をはじめる」・不正解・着目語の下線・連続日数／**貸付実務** |
| 紺 `#134E8C` | できた | 正解・段位・XP・実績／**資金需要者保護** |
| 紫 `#6A4A9C` | あとで見直す | 復習の期日・付箋・頻出／**財務会計** |

主色が深緑なのは、同じ4,554本のスクショを画素で測り直した色調査（`research/緑基調アプリ300.md`）の結果です。
学習アプリ全体では青が41.6%と最多ですが、「過去問」を名乗るアプリでレビュー300件以上に絞ると
**緑34.5%（1位）／青6.9%** と逆転し、宅建 `#01843A`・行政書士 `#03843A`・ITパスポート `#279F00`・
公務員 `#01602F` といった首位グループはすべて深緑でした。主色の `#0F7A3C` はその実測値に合わせています。
主色が緑になったぶん、「できた」を表す色（正解・段位・実績）は紺に移しました。

`--ng`（不正解）は朱、`--gold`（段位・実績）は紺の別名にしてあり、実体は4色です。
正答率の3段階は **紺（60%以上）／深緑（30%以上）／朱** です。
到達度マトリクスの「全問一発正解」だけは4色すべての上に乗るため、色ではなく地色の縁取りで示しています。

文字は全画面メイリオ。採点時の朱書きの〇／✕は、日本の試験文化で通じる記号なので残しています。
ライト／ダーク両対応。

### 続けるための仕掛け

- **段位** — 解くほどXPが貯まり 十級 → 一級 → 初段 → 五段 と昇級
- **到達度マトリクス**（20回×5列） — 一度も間違えずに正解した割合を色の濃さで表示。
  全問一発正解のマスは白く縁取ります。押すとその範囲だけ演習できます
- **連続学習日数**と**1日の目標問題数**
- **実績12種** — 千問走破、満点の回、模試五冠、三十日連続 など
- **連続正解カウンタ**と、採点時の朱書きの〇／✕

キーボード：`1`〜`4` で解答、`←` `→` で移動、`f` で付箋。

### 解説を載せていない理由

正答は示しますが、解説文は入れていません。
最初にアップロードされた7ファイルの解説を検証したところ、令和6年・令和7年の2ファイルを除き、
**解説が実際の設問とは別の論点を説明している**状態でした（詳細は `検証結果.md`）。
誤った解説は学習の妨げになるため、原文と公式正答だけを収録しています。

## 再生成

```bash
# 公式PDFを official/ に置いてから
python3 tools/parse.py            # PDF → db_raw.json
python3 tools/build.py            # 図表の手当て・分類付与 → db.json
python3 tools/verify_engine.py    # 別エンジン(pypdfium2)との照合
python3 tools/verify_thirdparty.py # 他社データとの照合
```

アプリの再ビルドは `app/template.html` の `/*__DATA__*/` `/*__META__*/` にJSONを差し込むだけです。
