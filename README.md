# 貸金業務取扱主任者 過去問データ＋学習アプリ

第14回（令和元年度）〜第20回（令和7年度）の全350問を、日本貸金業協会が公開している
公式PDFから機械的に取り込み、他社データと突き合わせて裏付けを取ったデータセットと、
それを使う学習アプリです。

```
data/questions.json   全350問（アプリ・プログラム用）
data/questions.csv    同上（表計算用・BOM付きUTF-8）
app/index.html        学習アプリ（単一ファイル。ダブルクリックで開けます）
app/template.html     アプリの雛形（データ注入前）
tools/                データ生成・検証スクリプト
検証結果.md            アップロードされた7ファイルの検証結果
```

## データ

| 項目 | 内容 |
|---|---|
| 収録範囲 | 第14回（2019年）〜第20回（2025年） 各50問・計350問 |
| 出典 | [日本貸金業協会 試験問題PDF・正答PDF](https://www.j-fsa.or.jp/chief/qualifying_exam/exam_example/law_11_20th.php) |
| 内容 | 問題文／ａ〜ｄの記述／選択肢①〜④／注記／正答／分野／出題形式 |

### 1問の構造

```json
{
  "id": "R20-01", "kai": 20, "era": "令和7年度", "num": 1,
  "sectionShort": "法令",
  "stem": "貸金業法上の用語の定義等に関する次のａ～ｄの記述のうち…",
  "statements": { "ａ": "…", "ｂ": "…", "ｃ": "…", "ｄ": "…" },
  "options": { "①": "1個", "②": "2個", "③": "3個", "④": "4個" },
  "note": "", "answer": 1,
  "format": "count", "negative": false
}
```

- `sectionShort` … 法令 ／ 貸付実務 ／ 資金需要者保護 ／ 財務会計
- `format` … `single`（単純択一）／ `combo`（組合せ）／ `count`（個数）
- `negative` … 「適切でないもの」を選ばせる否定形の設問かどうか
- `table` … 図表問題（2問のみ）に付く構造化された表

内訳：法令189問／貸付実務105問／資金需要者保護35問／財務会計21問。
形式別は単純択一280問／組合せ39問／個数31問。否定形は147問。

## データが正しいことの裏付け

3系統で突き合わせ、全項目が一致することを確認しています。

**1. 正答（350件）— 公式正答PDFと機械照合**
第14〜20回の正答PDFから抽出した数字をそのまま採用。350/350一致。

**2. 問題文・選択肢（1,400項目）— 他社データと照合**
過去問ドットコムの全350ページを取得し、選択肢①〜④とａ〜ｄの記述、計1,400項目を
順序に依存しない方法で突き合わせ。**1,399項目が一致**。

残る1項目（令和2年度 問9 記述ｃ）は他社側の誤記でした。
公式PDFは「貸付けの残高の合計額は **0円** であった」（数字のゼロ）ですが、
他社データは「**O円**」（アルファベットのオー）になっています。当データが公式どおりです。

**3. 問題文全体（350問）— アップロードされた7ファイルと照合**
330/350が高い一致度。残る20問の差分を個別に確認したところ、すべて7ファイル側の
問題（年度の取り違え・問番号の入れ替え・転記ミス・独自の注釈追加）で、
当データ側の誤りではありませんでした。

**抽出時の自動検査（全350問）**
選択肢が4つ揃っているか、ａ〜ｄが欠けていないか、注記が本文に混入していないか、
PDF由来の余分な空白が残っていないか等をすべて通しています。

### 元PDFの扱いで補正した点

- 埋め込みフォント由来の数字化け（`/c2691` → `1`）と全角数字の統一
- 版面の都合で行が割れた語（`第 1` ＋ 改行 ＋ `2条` → `第12条`）の結合
- 上付きの `(注)` と、末尾の注の定義文の切り分け
- 図表2問（令和2年度 問48・令和6年度 問48）は段組みが崩れるため表を手作業で構造化

## アプリ

`app/index.html` を開くだけで動きます。サーバー不要、通信も発生しません。
学習記録はブラウザの localStorage に保存されます。

- **分野別演習** — 年度・分野・出題形式・未解答／誤答で絞り込み、1問ずつ答え合わせ
- **模試** — 年度別50問を2時間で。終了後にその年の公式合格基準点で合否判定
- **復習** — 間違えた問題と付箋を付けた問題だけを出題
- **成績** — 分野別・年度別の正答率、模試の記録

キーボード：`1`〜`4` で解答、`←` `→` で移動、`f` で付箋。

### 解説を載せていない理由

アプリは公式の正答を示しますが、解説文は入れていません。
アップロードされた7ファイルの解説を検証したところ、令和6年・令和7年の2ファイルを除き、
**解説が実際の設問とは別の論点を説明している**状態でした（詳細は `検証結果.md`）。
誤った解説をそのまま載せると学習の妨げになるため、正答のみを収録しています。

## 再生成

```bash
# 公式PDFを official/ に置いてから
python3 tools/parse.py     # PDF → db_raw.json
python3 tools/build.py     # 図表の手当て・分類付与 → db.json
python3 tools/verify.py    # 他社データとの照合
```

アプリの再ビルドは `app/template.html` の `/*__DATA__*/` `/*__META__*/` に
JSONを差し込むだけです。
